# Кыргызский перевод интерфейса

Страницы написаны на русском, перевод на кыргызский делает `static/js/i18n.js` по словарю `static/js/i18n-ky.js`.
Словарь генерируется из `ky_dict.py` — переводы правятся только там.

После изменения текста на страницах:

```bash
cd tools/i18n
python3 extract.py ../../src/main/resources phrases.json   # собрать все русские фразы интерфейса
python3 build.py . ../../src/main/resources/static/js/i18n-ky.js -v   # собрать словарь и показать фразы без перевода
```

Фразы из списка «без перевода» добавьте в `ky_dict.py` и запустите `build.py` ещё раз.
Значки и знаки по краям (`📊 Оценки`, `+ Добавить`, `Войти →`) и числа учитываются автоматически.
